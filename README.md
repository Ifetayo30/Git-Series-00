# Git-Series-00
Ce dépôt sert à apprendre les bases de Git et de GitHub.
## 3.3 Introduction
Ce dépôt a été créé pour apprendre par la pratique les bases de Git et de GitHub.
Je débute dans l'utilisation de Git et de GitHub et je souhaite mieux comprendre la gestion des versions et l'organisation de mes projets. Dans le cadre de mon Master 2 en Ingénierie des Dispositifs pour la Santé, ces outils seront utiles pour gérer mes projets de programmation et d'analyse de données.
Cet exercice me permet de découvrir progressivement les branches, les commits et le partage des modifications avec GitHub.
J'ai hâte d'approfondir mes connaissances en Git et GitHub afin de pouvoir les utiliser efficacement dans mes futurs projets.
